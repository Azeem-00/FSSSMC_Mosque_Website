# FSSSMC Mosque Website

A modern and responsive mosque website built to provide information about the mosque, its leadership, events, programs, and community activities through a clean and accessible user experience.

## Live Demo

https://fsssmcmosque.netlify.app/

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and user-friendly interface
- Leadership and organizational information
- Community announcements and updates
- Events and activities section
- Contact information and communication channels
- Optimized navigation experience
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Goal

This project was developed to create a professional online presence for a mosque community while demonstrating frontend development skills including responsive design, user interface development, accessibility, and modern web design principles.
